How your files are handled

The tools read files you choose and process them in browser memory. This app has no file-upload endpoint, analytics tracker, hosted model call, or account system. The processing libraries are served with the site, rather than loaded from third-party CDNs.

Opening a page downloads its HTML, JavaScript and styles from GitHub Pages. “Try example files” downloads public sample files from this site. Those normal page requests do not contain your selected file contents.

The result is a browser-generated download. The Clear button releases the app’s file references and download URL. It does not delete your original files or downloads, and it cannot promise secure erasure of browser memory. GitHub Pages may retain normal request logs under its own policies.

External links open the services they point to; those sites have their own policies. Review the source code if your workflow has stronger confidentiality requirements.
