# Original example lecture excerpt

Synthetic teaching example for card planning; not a quotation from a real course.

- L1: An observation is a recorded result or event.
- L2: An inference is an explanation drawn from observations.
- L3: A hypothesis is a claim that can be checked against new observations.
- L4: For this unit, write each observation before its inference.
- L5: Tomorrow's seminar meets in Room 4.
- L6: Example: a wet pavement is an observation; "rain caused it" is an inference
  that may need checking.
- L7: These notes do not define a controlled variable; consult the assigned reading.

The cards are based only on these lines. L5 is a scheduling announcement,
and L7 records a source gap rather than supplying its answer.
