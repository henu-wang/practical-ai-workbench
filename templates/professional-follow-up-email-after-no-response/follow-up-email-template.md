# Professional follow-up email template

Original editable template. Replace every bracketed field before use. Keep the existing subject when replying in a thread; do not add another “Re:”. If starting a new message, use a specific subject such as “Follow-up: orientation room layout”.

```text
Subject: [Existing subject, or Follow-up: specific topic]

Hi [Recipient name],

I'm following up on [specific message or request] from [verified date].
Could you [one clear action or question]?

Thank you,
[Your name]
```

If a real planning need makes a reply date useful, replace the request sentence with:

```text
If possible, could you [one action] by [specific date] so I can [actual planning need]?
```

This is a new request, not an agreed deadline. If you refer to a promised reply date instead, verify its exact wording in the earlier correspondence. Omit a date when it is not needed. If the earlier date is unknown, use a verified subject or detail instead of guessing.

Check names, dates, any agreement, the single request, recipients and any attachment you actually intend to include. Silence does not prove receipt, rejection, approval or intent. Choose when to follow up from the actual context; this template sets no waiting period. Review and send manually if appropriate. No tool was run or message sent to create this template.
