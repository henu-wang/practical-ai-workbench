# Weekly report source collection worksheet

Use this before drafting. Record raw notes, not a previous model summary. Keep source IDs stable within the reporting pack. A source ID identifies a record, not independent verification of its truth.

## Collection context

- Project / readers / purpose: [supply all three].
- Reporting start and end, inclusive / timezone: [dates / timezone].
- Evidence cutoff / assembly day: [date/time / day].
- Desired report sections / length / recurring items: [supply].
- Confidentiality limits / redactions: [supply].
- Previous report, if available: [location or UNAVAILABLE].
- Agreed baseline and approved changes: [location / dates].

Before using asset 6860, supply goal, sources with actual retrieval paths, and the time window. Ask for missing essentials rather than guessing. Review its proposed collection plan and perform it yourself.

## Handoff to asset 6827 or a manual writer

Supply this context, original labelled notes, baseline and conflict/gap records. Request completed work and evidence, ongoing work, blockers, next steps and decisions/help. Preserve SINGLE-SOURCE, UNCLEAR and UNKNOWN explicitly; verify their survival after drafting. Do not pass a generated summary as if it were original evidence.

Keep the input pack, draft and human edits under a filename containing the reporting dates, for example `[project]-[start]-[end]-[inputs/report/edits].md`. Check the final report before manually sharing it.
