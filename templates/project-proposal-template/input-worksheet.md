# Proposal input worksheet

Original supporting worksheet. It prepares facts for a proposal; it is not the full TokRepo drafting prompt.
Keep reference labels stable so someone can verify the draft.

1. Working title: [title]
2. Problem and intended change: [known situation; goal is not an achieved result]
3. Reader and decision maker: [audience; desired decision]
4. Required work: [R1, R2, etc.; one requirement per line]
5. Hard limits: [supplied dates, effort, people, budget, tools, exclusions; identify UNKNOWN]
6. Acceptance checks: [what a reviewer should inspect]
7. Unresolved decisions: [owner, dates, dependencies, approval, or other gaps]
8. Source context: [F1, F2, etc.; quotes or notes you can use]
