# 读者内容规范

这是面向英语读者的开源实用项目，规范用中文，页面正文用自然英语。目标是让搜索者完成明确任务；不以资产名称或文章数量定义成功。

## 谁在读、要完成什么

每篇 brief 必须填：读者是谁、来时有什么输入、想得到什么输出、愿意付出多少步骤、为何这页比搜索到的普通文章更省事。通用入口优先不要求编程的办公、文档、创作或格式处理任务；开发者教程可以保留，但要明确分类，不能据此声称覆盖通用需求。

标题以任务动词和结果为中心。例如 “Convert SRT subtitles to VTT online” 可以匹配浏览器转换；“Whisper + FFmpeg stack” 只说明组件。题目必须准确描述实际交付，不能用“PDF converter”标题给读者一个仅处理粘贴文本的工具。

搜索需求和产品能力共同决定选题。联想词、真实提问、搜索结果页面可证实相关意图；只有可靠量化来源才可声称搜索量。要区分“有需求证据”“量化高需求”和“已获得访问”。

## 推荐页面结构

1. **一句直接答案。** 说明结果、输入范围和关键条件。不要从资产目录、AI 发展史或泛泛背景开头。
2. **工具或可复制产物。** 首屏可见操作入口；非技术用户无需安装库才能看见价值。表单标签清晰，带“Load sample”，输入错误应可恢复。
3. **真实小样例。** 展示最小有效输入、实际输出，以及复制/下载入口。示例和工具内样例共用同一 fixture，避免编辑后不同步。
4. **如何使用。** 写用户动作及其结果，不解释与选择无关的内部模块。常见任务在少量动作内完成；不能为了三步模板隐藏必要条件。
5. **适用条件与失败处理。** 具体写会丢什么、哪些格式/大小支持、错误如何修复。错误不能变成看似成功的空输出。
6. **下一步和 TokRepo。** 当前结果完成后，链接真正能帮助下一步的资产，并解释一条具体收益。只放相关资产，入口标注为外部链接。
7. **开源与贡献。** 链接源文件、许可和可操作的 issue 模板。用户可以复现、修复或扩展能力，而不是只能阅读软文。

不是每页都必须按这些标题排版；必须能找到这些内容。字数不是质量门槛，工具完成任务后几段清楚说明胜过长文。

## 英语写法

使用常见动词：paste, convert, check, copy, download。正文用短段落，优先具体输入与结果。不要宣称 “seamless”, “best”, “ultimate”, “100% accurate” 或 “guaranteed traffic”，除非确有能支持的范围和证据。

不要把 model、MCP、RAG、server、asset taxonomy 放进日常用户不必理解的路径。库名放于 “How it works” 或进阶实现说明。不要用无意义场景装点功能；示例应直接证明核心行为。

可写：“Paste an SRT file to create a downloadable WebVTT file. Styling and positioning may need manual review.” 不可写：“Generate perfect captions for any video”，如果页面只能变换现有字幕格式。

“Runs locally” 仅在实际数据流检查支持时使用。浏览器工具不得把“没有后端 API”直接升级为“绝不发送任何数据”；远程脚本、分析请求及外链加载也要核对。说明页面实际处理路径，不写泛泛隐私保证。

## 产物、实验和版本用语

- **Observed / tested：** 记录具体命令或浏览器动作、fixture、版本、时间、实际输出。
- **Example / template：** 是示范或起点；不能作为已执行的结果。
- **Expected：** 是应该出现的结果，不是运行记录。
- **Supported：** 必须有规范及覆盖的用例；不支持的输入给清楚错误或限制。

代码需可下载，并含依赖/运行说明。版本能影响复现时固定版本；不要只让用户“选择已测试版本”而不给版本。模型输出有随机性时保留真实运行记录，不做确定性承诺。示例中的数字必须来自 fixture 或真实执行，不能虚构基准。

## CTA 编辑标准

CTA 不以“visit TokRepo”结束。应解释与当前工作相关的下一步，例如 “Need to generate the first transcript? See the Whisper asset and its local setup requirements.” 路径必须是已核验的具体 `/en/workflows/<slug>`，不能只链首页。若该工具未使用这个库，不暗示是集成依赖；可以标为可选延伸。

每篇只保留能解释作用的资产链接。禁止每页堆同一组无关资产、隐藏 SEO 链接、借流量题目导向不同任务。公共内容不得带私有 token、账户截图、内部日志或未经授权的文件。
