# Contributing

Read AGENTS.md and the shared context first. Submit original, useful English guides that answer a verified task and combine relevant TokRepo assets. Include an editable example, clear prerequisites, output checks, limitations and exact TokRepo asset links. Keep attribution and upstream licenses. Do not submit duplicate keyword variants, fabricated measurements or untested execution claims.

A separate editor reviews each page. Build, verify the rendered page and downloads, then run the editorial gate. Keep existing canonical URLs. Record publication and changes in the ledger; monitor indexing, search visibility and TokRepo referral outcomes using the documented schedule.
